# Clairose 🌸

**Little things. Lovely living.**

Clairose is a fictional lifestyle boutique and front-end e-commerce project designed to explore modern storefront design, interactive shopping experiences, and responsive web development.

The project features a soft, elegant visual identity with powder pink, sage green, white, and charcoal accents. Its interface is designed to create a welcoming shopping experience while demonstrating practical front-end development skills.

## Features

- Elegant homepage and storefront layout
- Product catalog featuring 20 fictional products
- Product collections and categories
- Individual product detail pages
- Interactive shopping bag
- Add, remove, and update product quantities
- Dynamic subtotal and pricing calculations
- Demonstration checkout with order confirmation
- Dedicated Image Credits page with source attributions

## Technologies Used

- **HTML5** - Website structure
- **CSS3** - Styling, layout, and responsive design
- **JavaScript** - Interactive functionality and dynamic content
- **Local Storage** - Shopping bag data persistence

## Design Direction

Clairose uses a soft, feminine, and minimal visual direction inspired by modern lifestyle boutiques.

**Color Palette**
- Powder Pink `#E8BFCB`
- Soft White `#FFFFFF`
- Sage Green `#C5D4C1`
- Muted Sage `#A6B39F`
- Soft Black `#252525`
- Warm Charcoal `#454545`

## Project Purpose

Clairose was created as a portfolio project to demonstrate front-end development, interface design, JavaScript functionality, and the construction of an interactive e-commerce experience.

The project explores how visual branding and functional website elements can work together to create a cohesive digital storefront.
